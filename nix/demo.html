CONTAINERS ANYWHERE

Containers Anywhere works.

Your browser reached a real workload running inside the appliance.

Browser → native Caddy → authenticated VM bridge → Traefik → demo Caddy pod

This page is served by a preloaded Kubernetes Deployment, not by the desktop launcher. It needs no external fonts, scripts, images, or internet connection.

Bring your own workload

  1. Deploy your application and a Kubernetes Service through Kite or your workload manager.
  2. Have the appliance owner approve your namespace and hostname suffix.
  3. Create an Ingress with ingressClassName: containers-anywhere. The appliance provides local HTTPS; Traefik routes requests to your Service.

What this page proves

A successful request proves the application traffic path is responding. Reaching it from a second device using demo.local, without a hosts override, additionally exercises LAN reachability and name resolution.

This non-sensitive demo is also available over HTTP so a new device can verify connectivity before certificate enrollment. Applications use HTTPS. To enable trusted HTTPS, obtain this installation's public CA certificate from your appliance administrator and install it through your device's trust settings. Verify its identity with the administrator; an HTTP download alone does not authenticate a certificate.

No telemetry. No credentials. No patient data. This public demo is not a management console or a production-readiness certification.
